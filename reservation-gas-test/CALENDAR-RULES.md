# 方法別の予約不可設定（作業用・Google側は未反映）

- メインカレンダーの通常の「予定あり」：すべての相談方法が予約不可。
- 「【対面NG】」で始まる「予定あり」：対面のみ予約不可。オンライン・チャット・電話は候補に残ります。
- 「空き時間」に設定した予定：予約をブロックしません。
- 仮予約が入った時間：相談方法を問わず予約不可です。
- 予定のタイトル・詳細は空き状況の応答に含めません。
- 例：「【対面NG】外出」を13:00〜15:00に入れると、対面の13時・14時開始枠が選択不可になります。
- 予定を削除するか「空き時間」に変更すると、ほかの予定や締切に該当しなければ再度選択できます。

方法を切り替えると時間の選択を解除し、最新の空き状況を取得します。送信時にもサーバーで再確認します。

この変更は公開用cloudflare-siteブランチと実際のApps Scriptにはまだ適用していません。前日20時締切・連続登録制限と一緒にまとめて反映予定です。
